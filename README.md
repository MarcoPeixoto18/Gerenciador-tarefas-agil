# Gerenciador de Tarefas Ágil

Projeto desenvolvido para fins acadêmicos, aplicando conceitos de engenharia de software, CRUD em Python, Metodologia Ágil e Integração Contínua (CI/CD) com GitHub Actions.

## 🚀 Tecnologias Utilizadas
- **Python 3.10+**
- **Pytest** (para testes unitários)
- **GitHub Actions** (para automação de CI/CD)
- **Git & GitHub Desktop** (para controlo de versões e commits semânticos)

## 📋 Funcionalidades (CRUD)
1. **Adicionar Tarefa:** Registo de novas tarefas com título e nível de prioridade (Baixa, Média, Alta).
2. **Listar Tarefas:** Visualização de todas as tarefas cadastradas.
3. **Filtrar por Status:** Filtragem de tarefas entre pendentes e concluídas.
4. **Atualizar Tarefa:** Modificação do título ou da prioridade de uma tarefa existente.
5. **Remover Tarefa:** Exclusão de tarefas do sistema.

## 🧪 Como Executar os Testes Localmente
Certifique-se de ter o Python e o `pytest` instalados, depois execute o seguinte comando no terminal na raiz do projeto:

```bash
pytest
